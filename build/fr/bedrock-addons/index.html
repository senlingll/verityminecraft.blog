Questions fréquentes sur les add-ons Bedrock

Comment installer des add-ons Minecraft Bedrock ?

Ouvrez un paquet Bedrock avec Minecraft, importez-le, puis activez-le dans le monde.

.mcaddon et .mcpack sont-ils identiques ?

Non, .mcaddon combine souvent plusieurs parties; .mcpack est souvent un pack unique.

Puis-je utiliser un .jar Java ?

Non, un .jar appartient à Java Edition.

Pourquoi l'add-on ne marche pas ?

Il peut être inactif, incomplet, incompatible ou dépendre d'un réglage.

Où télécharger des add-ons Bedrock ?

Préférez les sources officielles, créateur, marketplace, CurseForge ou MCPEDL.
