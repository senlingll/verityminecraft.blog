Tipo de arquivo: .mcaddon, .mcpack, .jar

.mcaddon costuma combinar comportamento e recursos. .mcpack é um pacote Bedrock individual. .jar é para Java Edition.

Essa diferença separa o baixamento Verity Bedrock do mod Java.
