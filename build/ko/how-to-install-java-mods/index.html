자바 모드 가이드

마인크래프트 자바 모드 설치 방법: 안전한 7단계

마인크래프트 자바 모드를 설치할 때는 모드가 지원하는 게임 버전과 로더를 먼저 맞춥니다. 별도 프로필에 로더를 설치하고 원본 .jar 파일을 그 프로필의 mods 폴더에 넣은 뒤, 주 월드를 열기 전에 테스트하세요.

Fabric, Forge와 비슷한 자바 프로필을 위한 안내입니다. Bedrock .mcaddon을 자바 모드로 바꾸는 방법이 아니며, 파일 출처를 숨기는 미러나 런처도 권장하지 않습니다.

빠른 결론

짧은 규칙: 로더를 먼저 맞추고 파일을 넣기

마인크래프트 자바 모드 설치에서 가장 안전한 방법은 모드마다 호환되는 프로필을 사용하는 것입니다. 모드 페이지에 지원하는 마인크래프트 버전과 로더가 표시되어야 하며, 파일을 다운로드하기 전에 프로필도 같은 조합으로 맞춰야 합니다.

Fabric과 Forge는 서로 바꿔 사용할 수 있는 폴더나 실행 방식이 아닙니다. NeoForge를 대상으로 하는 프로젝트도 있고, 모두 .jar를 사용하더라도 로더가 다르면 로드되지 않을 수 있습니다. 깨끗한 프로필에서 시작하고 파일 이름을 바꾸지 말고 하나씩 추가하세요.

현재 마인크래프트 자바 릴리스와 개별 프로젝트의 릴리스는 별개입니다. 2026년 8월 4일 공식 버전 목록을 확인했을 때 최신 릴리스는 26.2였지만, 기존 Verity JE 출처에는 Forge 1.20.1용 파일이 표시되어 있었습니다. 숫자만 비교하지 말고 실제 프로필과 파일의 호환성을 확인하세요.

자바 전용

자바 모드는 보통 .jar로 배포되며 Bedrock 가져오기 화면이 아니라 자바 모드 프로필에 들어갑니다.

로더가 핵심

모드 페이지에 적힌 Fabric, Forge 등의 로더를 선택하고 같은 게임 버전용으로 설치합니다.

섞기 전에 테스트

깨끗한 프로필과 복사한 월드를 사용하면 버전 오류와 의존성·모드 충돌을 구분하기 쉽습니다.

설치 순서

마인크래프트 자바 모드 설치 7단계

아래 확인을 순서대로 진행하세요. 다운로드 버튼이나 오래된 복사 글이 아니라 파일과 프로필의 호환성을 직접 판단하는 과정입니다.

1

1. Java Edition인지 확인하기

공식 런처나 평소 사용하는 프로필을 엽니다. Bedrock, Minecraft PE, 콘솔은 다른 콘텐츠 시스템을 사용합니다. 파일이 .mcaddon 또는 .mcpack이라면 이 자바 .jar 절차의 대상이 아닙니다.

2

2. 제목이 아니라 모드 페이지 읽기

마인크래프트 버전, 로더, 의존성, 파일 이름을 기록합니다. '마인크래프트 지원'이라고만 적힌 페이지는 안전한 프로필을 고르기에 정보가 부족합니다.

3

3. 호환되는 로더 설치하기

선택한 버전에 맞는 Fabric 공식 설치 프로그램이나 Forge 공식 파일 페이지를 사용합니다. 가능하면 별도 프로필을 만들고 모드를 추가하기 전에 한 번 실행하세요.

4

4. 관리되는 출처에서 받기

Modrinth 또는 CurseForge 프로젝트 페이지, 제작자가 안내한 페이지처럼 프로젝트 정체성과 버전 이력이 보이는 출처를 우선합니다. 버튼이 빠르다는 이유로 수정된 설치 프로그램이나 미러를 고르지 마세요.

5

5. 원본 .jar를 올바른 mods 폴더에 넣기

다른 설치의 공용 폴더가 아니라 호환되는 프로필의 mods 폴더를 엽니다. 확장자와 파일 이름은 유지하세요. 로더가 첫 실행 뒤 폴더를 만들면 게임을 종료한 뒤 파일을 복사합니다.

6

6. 의존성을 확인하고 프로필 테스트하기

모드에는 라이브러리, API 또는 설정 파일이 필요할 수 있습니다. 호환되는 의존성만 추가하고 최소 구성으로 실행하세요. 다른 파일을 다시 받기 전에 첫 오류 메시지를 확인합니다.

7

7. 주 월드 전에 복사본에서 테스트하기

새 월드나 복사한 월드에서 예상 기능을 확인하고 정상 종료합니다. 이후 다른 모드를 하나씩 추가하면 첫 문제에서 충돌 후보를 찾을 수 있습니다.

출처와 호환성

자바 모드를 받기 전에 확인할 5가지

프로젝트 페이지와 파일 페이지는 역할이 다릅니다. 프로젝트 페이지는 모드의 기능을 설명하고, 파일 페이지는 해당 빌드의 마인크래프트 버전·로더·의존성을 표시합니다. 오늘 설치할 때는 파일에 붙은 정보를 사용하세요.

로더 이름을 자세히 확인합니다. Fabric, Forge, NeoForge 모드는 모두 .jar일 수 있지만 로더는 호환성의 일부입니다. 하나의 프로젝트가 여러 로더용 파일을 제공한다면 가장 최신처럼 보이는 이름이 아니라 내 프로필에 맞는 파일을 선택합니다.

의존성도 확인하세요. Fabric API 같은 라이브러리나 로더별 지원 모드가 필요할 수 있습니다. 실행 오류에 부족한 라이브러리가 표시되는 경우가 있으므로 이름과 버전을 기록한 뒤 찾아보세요.

다운로드가 정말 모드인지도 구분해야 합니다. 셰이더, 리소스 팩, 데이터 팩, 모드팩, 자바 모드는 검색 결과에서 섞이지만 폴더와 로딩 규칙은 다릅니다. 셰이더 .zip을 mods에 넣거나 Bedrock 애드온 이름을 바꿔도 변환되지 않습니다.

마지막으로 출처 정보를 보관합니다. 프로젝트 URL, 파일 이름, 로더, 마인크래프트 버전, 확인 날짜를 메모하면 페이지가 업데이트되어도 오래된 글 하나만 믿지 않고 변경점을 확인할 수 있습니다.

호환성 표

자바 모드가 로드되려면 무엇이 같아야 하나요?

설치 전에 아래 표를 빠르게 확인하세요. 눈에 띄는 다운로드 버튼만으로는 호환성을 판단할 수 없습니다.

확인 항목맞춰야 할 것중요한 이유
마인크래프트 버전파일에 표시된 정확한 게임 버전다른 버전용 모드는 로딩에 실패하거나 예측하기 어려운 동작을 할 수 있습니다.
로더Fabric, Forge, NeoForge 또는 프로젝트가 지정한 로더로더가 모드가 기대하는 훅과 프로필 환경을 제공합니다.
파일 형식자바 모드는 .jar, 팩과 셰이더는 별도 형식확장자를 바꿔도 콘텐츠 시스템이 변환되지 않습니다.
의존성필요한 API, 라이브러리와 호환 버전메인 모드가 있어도 필수 라이브러리가 없으면 시작하지 못합니다.
출처와 날짜관리되는 페이지와 최근 확인미러는 오래된 빌드나 이름이 바뀐 파일을 남길 수 있습니다.

프로필과 문제 해결

주 월드를 지키면서 mods 폴더 찾기

mods 폴더는 자바 설치 또는 프로필에 속합니다. 정확한 위치는 런처와 운영체제에 따라 다르고, 사용자 지정 런처는 별도의 인스턴스 폴더를 사용할 수 있습니다. 처음 찾은 .minecraft 폴더가 실제 실행 위치라고 단정하지 말고 프로필 설정을 확인하세요.

Windows 기본 런처의 일반적인 게임 디렉터리는 AppData 안에 있습니다. 하지만 프로필과 외부 런처가 경로를 바꿀 수 있습니다. 선택한 프로필을 한 번 실행하고 로그나 저장 월드가 생기는 위치를 확인한 뒤 그 인스턴스의 mods 폴더를 사용하세요.

깨끗한 프로필에 대상 모드와 필요한 의존성만 추가합니다. 타이틀 화면까지 들어가면 복사한 월드에서 예상 기능을 확인하세요. 충돌하면 가장 최근 파일을 제거하고 다시 시작합니다. 한 번에 하나만 바꾸는 방식이 여러 번 다운로드하는 것보다 원인을 잘 보여줍니다.

모드가 나타나지 않으면 활성 프로필과 로더, 폴더 경로, .jar 확장자, 게임 버전, 의존성, 로그 메시지 순서로 확인합니다. 다른 로더나 버전의 파일을 억지로 사용하지 말고 호환되는 프로필 또는 파일을 고르세요.

깨끗한 테스트가 성공한 다음 평소 쓰는 모드를 조금씩 추가합니다. 프로젝트 URL, 파일 이름, 로더, 마인크래프트 버전, 날짜를 목록으로 남겨두면 업데이트 뒤 월드가 열리지 않을 때 변경점을 추적하기 쉽습니다.

자주 하는 실수

자바 모드가 나타나지 않거나 충돌하는 이유

대부분은 호환성이나 파일 관리 문제입니다. 다른 미러를 찾는다고 해결되는 문제는 아닙니다.

마인크래프트 버전 불일치

런처는 실행되어도 모드가 다른 버전을 대상으로 하면 거부됩니다. 파일과 프로필을 정확히 맞추세요.

잘못된 로더

둘 다 .jar라고 해서 Fabric 파일이 Forge 모드가 되지는 않습니다. 프로젝트가 지정한 로더를 설치하세요.

팩과 모드 혼동

셰이더, 리소스 팩, 데이터 팩은 다른 폴더를 씁니다. 옮기기 전에 프로젝트 유형을 확인하세요.

의존성 누락

메인 모드를 정상적으로 받았어도 API나 라이브러리가 필요할 수 있습니다. 프로젝트 목록을 따르세요.

여러 파일을 한 번에 추가

모드팩 전체를 넣으면 첫 오류의 원인이 가려집니다. 모드 하나와 복사한 월드부터 시작하세요.

미러를 공식 출처로 착각

재배포 파일은 오래되었거나 원치 않는 설치 프로그램을 포함할 수 있습니다. 관리되는 페이지를 우선하세요.

마인크래프트 자바 모드 설치 FAQ

버전을 섞지 않고 마인크래프트 자바 모드를 설치하려면 어떻게 하나요?

파일 페이지에서 버전과 로더를 확인하고, 별도 프로필에 로더를 설치한 뒤 원본 .jar를 해당 mods 폴더에 넣습니다. 처음에는 필요한 의존성만으로 테스트하세요.

마인크래프트 자바 모드는 Fabric과 Forge 중 무엇이 더 좋은가요?

항상 한쪽이 더 좋은 것은 아닙니다. 설치하려는 모드나 컬렉션이 지정한 로더를 사용하세요. Fabric, Forge, NeoForge의 호환 생태계는 서로 다릅니다.

마인크래프트 자바 mods 폴더는 어디에 있나요?

활성 Java 프로필이 사용하는 게임 디렉터리 안에 있습니다. Windows에서는 AppData가 일반적이지만 사용자 지정 런처는 다른 인스턴스를 사용할 수 있으므로 프로필 설정을 확인하세요.

마인크래프트 자바 모드가 나타나지 않는 이유는 무엇인가요?

활성 프로필과 로더, 경로, .jar 확장자, 게임 버전, 의존성을 확인하세요. 충돌이 나면 다른 파일을 받기 전에 첫 오류를 읽습니다.

자바 모드를 Minecraft Bedrock이나 PE에 설치할 수 있나요?

할 수 없습니다. Java 모드와 Bedrock 애드온은 시스템과 파일 형식이 다릅니다. .jar 이름을 바꾸지 말고 Bedrock 또는 PE 가이드를 사용하세요.

TLauncher 같은 서드파티 런처를 사용할 수 있나요?
