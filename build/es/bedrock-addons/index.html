Guía de addons Bedrock

Tipo de archivo: .mcaddon, .mcpack, .jar

.mcaddon suele agrupar comportamiento y recursos. .mcpack normalmente es un paquete Bedrock individual. .jar pertenece a Minecraft Java Edition y no debe importarse en Bedrock.

Esta diferencia evita mezclar la descarga Bedrock de Verity con el mod Java. Si el archivo es .jar, vuelve a la guía Java en vez de renombrarlo.

Guía de addons Bedrock

Activar en una copia

Bedrock puede importar un paquete globalmente sin cambiar el mundo actual. Por eso el mensaje de importación no significa que el addon ya funcione.

Una copia del mundo protege tu partida principal. Si el addon funciona en la copia, decide después si lo activas en el mundo real.

Errores comunes

Revisa estos puntos antes de reemplazar el archivo.

Importado pero inactivo

El paquete no está activo en el mundo de destino.

Edición equivocada

Un archivo Java no funciona como addon Bedrock.

Versión distinta

El paquete puede apuntar a otra versión de Bedrock.

Espejo obsoleto

Prefiere fuentes con fecha y contexto del creador.

Límites de servidor

Realms o servidores pueden requerir ajustes del propietario.

Preguntas frecuentes sobre addons Bedrock

¿Cómo instalar addons en Minecraft Bedrock?

Descarga un paquete Bedrock de una fuente mantenida, ábrelo con Minecraft, espera la importación y actívalo en la configuración del mundo.

¿.mcaddon es igual que .mcpack?

.mcaddon suele combinar partes del addon; .mcpack suele ser un paquete individual.

¿Puedo usar mods .jar en Bedrock?

No. Los .jar son para Java Edition.

¿Por qué se importó pero no funciona?

Puede no estar activo, faltar una dependencia, requerir experimentos o apuntar a otra versión.

¿Dónde descargar addons Bedrock?

Prefiere fuentes oficiales, creador, marketplace, CurseForge, MCPEDL o páginas mantenidas con fecha.
