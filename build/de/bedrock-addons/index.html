Dateityp: .mcaddon, .mcpack, .jar

.mcaddon enthält oft Verhalten und Ressourcen. .mcpack ist meist ein einzelnes Bedrock-Paket. .jar ist für Java Edition.

So bleiben Verity Bedrock und Verity Java sauber getrennt.

Häufige Fragen zu Bedrock-Add-ons

Wie installiert man Minecraft Bedrock Add-ons?

Bedrock-Paket mit Minecraft öffnen, importieren und in der Welt aktivieren.

Sind .mcaddon und .mcpack gleich?

.mcaddon kombiniert oft mehrere Teile, .mcpack ist meist ein Einzelpaket.

Kann ich .jar nutzen?

Nein, .jar ist für Java Edition.

Warum funktioniert es nicht?

Inaktiv, fehlende Abhängigkeit, Experiment oder Versionsproblem.

Wo lädt man Bedrock-Add-ons herunter?

Offizielle, Ersteller-, Marketplace-, CurseForge- oder MCPEDL-Seiten bevorzugen.
